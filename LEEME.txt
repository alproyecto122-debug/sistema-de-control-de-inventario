ERP REFACCIONES - VERSIÓN PORTABLE

1. Abre index.html con doble clic.
2. No requiere Laragon, PHP, MySQL, Railway ni Render.
3. Los datos se guardan en el navegador del dispositivo mediante almacenamiento local.
4. Usa "Exportar respaldo" para guardar una copia JSON de tus datos.
5. Usa "Importar respaldo" para recuperar o trasladar los datos a otro navegador/dispositivo.

IMPORTANTE:
- Si abres el archivo en otro celular o computadora, los datos NO se sincronizan automáticamente.
- Para que todos los dispositivos compartan el mismo inventario en tiempo real se necesita una base de datos en línea.
- Esta versión conserva las funciones principales: Dashboard, inventario, equipos, movimientos, stock mínimo, alertas, búsqueda, edición y eliminación.

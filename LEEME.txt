ERP REFACCIONES - VERSIÓN CON SUPABASE

Esta versión:
- Funciona en GitHub Pages.
- No requiere Laragon, PHP, MySQL, Railway ni Render.
- Guarda inventario y movimientos en Supabase.
- PC, celular y tablet comparten los mismos datos.
- Requiere conexión a Internet.

PARA ACTUALIZAR GITHUB:
1. Abre tu repositorio sistema-de-control-de-inventario.
2. Abre index.html.
3. Reemplaza el archivo actual por este index.html (o elimina/sube el nuevo).
4. Haz Commit changes.
5. Espera 1-2 minutos a que GitHub Pages se actualice.
